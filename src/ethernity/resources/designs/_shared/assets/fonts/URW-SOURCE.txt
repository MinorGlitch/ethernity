Nimbus Sans, Nimbus Mono PS, and Nimbus Roman

Unmodified TrueType files from URW Base 35, distributed by Artifex Software.
Source revision: 3c0ba3b5687632dfc66526544a4e811fe0ec0cd9
https://github.com/ArtifexSoftware/urw-base35-fonts/tree/3c0ba3b5687632dfc66526544a4e811fe0ec0cd9

These replace unembedded Helvetica, Courier, and Times in Ethernity's PDFs.
Only the five faces used by the built-in templates are bundled. The renderer
subsets the embedded font programs to the glyphs used in each document.

See URW-COPYING.txt for the AGPL-3.0 license and URW-LICENSE.txt for the
exception permitting embedding in PostScript and PDF documents regardless of
the document's license. The source repository includes Type 1, OpenType,
TrueType, and AFM files for these fonts.
